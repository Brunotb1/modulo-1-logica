# Módulo 1 — Lógica de Programação

Projetos desenvolvidos durante o estudo de lógica de programação com Python.

## Conteúdo aprendido

- Variáveis e tipos de dados (int, float, str, bool)
- Entrada de dados com input()
- Operadores aritméticos e de comparação
- Condicionais (if, elif, else)
- Loops (for, while)
- Listas e índices
- F-strings

## Arquivos

- `variaveis.py` — exemplos de variáveis e tipos
- `operadores.py` — cálculo de dados pessoais e IMC com condicionais
- `loops.py` — exemplos de for, while e listas
- `desafio.py` — tabuada interativa
- `sistema_de_cadastro_muito_simples.py` — projeto final

## Projeto Final

Sistema de cadastro simples no terminal com menu interativo.
Permite cadastrar pessoas com nome, idade e cidade,
listar todos os cadastros e sair do programa.

## Como executar

```bash
python sistema_de_cadastro_muito_simples.py
```
